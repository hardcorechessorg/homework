Сгенерированная ссылка
Новый способ загрузки долгов!
К сожалению, стандартный способ больше не работает. Чтобы всё работало как раньше — надо выполнить следующие шаги:
1
Установи Tampermonkey
Расширение для браузера, которое выполняет твои скрипты на нужных сайтах. Доступно для Chrome, Firefox, Edge, Opera:
  • tampermonkey.net
2
Создай новый скрипт
Открой иконку Tampermonkey в браузере → Dashboard → вкладка «+» (новый скрипт).
3
Скопируй код скрипта
Нажми на кнопку ниже — весь код скопируется в буфер обмена.
4
Вставь и сохрани
В редакторе Tampermonkey замени всё содержимое — вставь Ctrl+V — сохрани Ctrl+S.
5
Готово
Теперь просто открываешь ссылку из генератора выше — выбираешь файл — жмёшь execute upload. Больше никакой консоли.
